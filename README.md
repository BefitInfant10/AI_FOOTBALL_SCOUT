# AI Football Scout

AI Football Scout is a computer vision project that analyzes football match videos using Artificial Intelligence. The current implementation focuses on detecting and analyzing passes and shots from football matches, with the goal of expanding into a complete football analytics platform.

## Current Features

- Pass Detection
- Shot Detection
- Football Match Video Analysis
- Event Detection using Computer Vision

## Technologies Used

- Python
- OpenCV
- YOLO
- NumPy
- Pandas
- Ultralytics

## Current Progress

The project is currently in development. At present, it can detect and analyze passes and shots from football match footage. Additional analytics features are planned to make it a comprehensive football analysis system.

## Planned Features

- Player Detection
- Ball Tracking
- Player Tracking
- Team Classification
- Possession Analysis
- Heat Maps
- Player Speed Estimation
- Expected Goals (xG)
- Formation Analysis
- Tactical Dashboard
